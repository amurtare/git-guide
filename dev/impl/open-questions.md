# git-guide 구현 미검증·미결 장부

구현 단계(Design → Impl 게이트 이후)의 미검증·미결을 모은다. **설계 중 미결·실측은 [`dev/plan/open-questions.md`](../plan/open-questions.md)**다.

## 운영 규칙

- **무엇을 넣나**: ① 실제 브라우저로 못 본 동작, Pro Git 원고로 확인하지 못한 설명·용어 ② 검수의 빈틈 ③ 외부 환경 의존 가정(브라우저 정책, GitHub 등) ④ 부작용 때문에 미룬 실행 ⑤ 미이행·미결정
- **언제**: 각 구현 단계를 마칠 때(커밋 전) — 새 항목 추가 + 해소된 항목 정리
- **해소되면**: 항목을 지우고 결과를 `project-memory/gotchas.md`(사실) 또는 `project-memory/decisions/<주제>.md`(정책)로 옮긴다. `progress.md`에는 ID만 적는다
- **ID**: 구획 문자 + 번호. 지운 ID는 재사용하지 않는다. 앞단 장부와 ID가 겹치지 않도록 이 장부는 새 구획 문자(`I`부터)를 쓴다
