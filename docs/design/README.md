# 설계 문서

레슨과 공용 도식의 **설계 단일 진실 소스**다. 구현(`index.html`, `lessons/`, `assets/`)과 진행 기록(`impl/`)은 여기에 맞춘다.
설계를 바꾸려면 사용자와 의논해 이 폴더를 먼저 고친다 ([impl/README.md](../../impl/README.md) R3).

| 문서 | 내용 | 상태 |
|---|---|---|
| `diagram-model.md` | 로컬·리모트 공용 도식 틀 (R1) | 미작성 — `impl/checklist.md` Phase 0 |
| `lesson-00.md` | 0단계 흐름: 로컬/서버 버전 관리 개념부터 (R2) | 미작성 — `impl/checklist.md` Phase 0 |

레슨별 설계 문서(`lesson-NN.md`)는 해당 단계 플랜이 승인될 때 추가한다.
