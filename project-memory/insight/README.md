# insight/

raw 메모 보관소.

- **파일명**: `YYYY-MM-DD-<kebab-case>.md`
- **본문 필수 줄**: `**컨텍스트**: ...` (어떤 작업 중에 나온 메모인지 한 줄)
- **저장 트리거**: 사용자가 명시적으로 요청하면 즉시 저장. 에이전트가 감지한 경우에는 제안만 하고 자동 저장하지 않는다.
- **승격(graduation)**: 두 번 이상 참조되면 decisions/ · gotchas.md · components.md로 옮기고 원본은 삭제한다.
- **정리**: 릴리즈 때 6개월 이상 참조되지 않은 메모는 삭제한다.
