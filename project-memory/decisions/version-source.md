# 버전 소스: 루트 `VERSION` 파일

**결정 (2026-10-13)**: 버전 번호는 루트의 plain-text `VERSION` 파일에만 정의한다.

**이유**
- 빌드 도구가 없는 정적 HTML 프로젝트라 `package.json` 같은 매니페스트가 없다. 버전 하나 때문에 매니페스트를 만들면 Node 프로젝트로 오해받는다.
- plain-text라 셸·hook·사람 모두 읽기 쉽다 (`cat VERSION`).

**알려진 제약**
- `file://`로 연 페이지는 `fetch("VERSION")`이 브라우저 보안 정책으로 막혀서, 페이지가 이 파일을 런타임에 읽을 수 없다.
  화면에 버전을 표시하려면 HTML에 값을 직접 적어야 하고, 이건 두 번째 사본이 된다.
  → 릴리즈 체크리스트 1번에서 두 값이 같은지 확인하는 것으로 대응한다. 자동화 방법은 [open-questions.md](../open-questions.md) 참고.
