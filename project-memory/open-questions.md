- **관찰**: `file://` 환경에서는 페이지가 `VERSION`을 읽을 수 없어, 푸터의 버전을 HTML에 직접 적어야 한다 (사본 2개).
- **가설·시도**: (a) 체크리스트로 수동 확인 (현재 방식) (b) `assets/js/version.js`를 버전 소스로 삼고 `VERSION`을 없앤다 (c) 릴리즈 시 두 값을 비교하는 작은 스크립트를 둔다.
- **다음 단계**: `index.html`을 만들 때 결정한다.
